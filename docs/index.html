Vue d'ensemble

Comment lire : les graphiques ne portent que sur les signaux notifiés (bot, manuels, propositions), jamais sur les fantômes. « Hasard attendu » = taux de réussite qu'obtiendrait une pièce jetée avec les mêmes TP et SL ; c'est la barre à dépasser.

Demander un trade

Envoyer ce signal : vous choisissez le sens et, si vous voulez, vos propres objectif et stop ; laissés vides, le bot les calibre sur la volatilité du moment. Il notifie et suit le trade (source « manuel »).
Proposer un trade : le bot analyse l'actif choisi maintenant, envoie sa lecture des indicateurs et, s'il voit une direction, une proposition calibrée avec son verdict honnête (passe ou non ses critères), suivie sous la source « proposition ».
Les boutons fonctionnent dès maintenant ; les statistiques apparaissent quand les données sont chargées.
