Règles des comptes Topstep 50K

Trading Combine 50K (évaluation)

  • Objectif : +3 000 $ (balance de 53 000 $).
  • Perte maximale (MLL) : 2 000 $ sous le plus haut solde de fin de journée. Elle démarre à 48 000 $, monte avec vos journées gagnantes et s'arrête à 50 000 $.
  • Limite journalière (DLL) : 1 000 $ par jour, si vous l'activez. Atteinte : plus de trade ce jour-là, le compte reste valide.
  • Cohérence : votre meilleure journée ne dépasse pas 50 % du gain total. Sinon, l'objectif augmente (ex. meilleure journée de 2 000 $ → 4 000 $ de gain à atteindre).
  • Taille maximale : 5 contrats standards ou 50 micros en même temps.
  • Fermer avant 15:10 heure de Chicago (22:10 à Paris, 21:10 pendant le décalage de printemps et d'automne). Topstep ferme lui-même à partir de 15:08.
  • Journée de trading : de 17:00 à 17:00 heure de Chicago (00:00 à Paris). Un trade du soir compte pour le lendemain.
  • Prix : 49 $ par mois, puis 149 $ d'activation une fois l'évaluation réussie (formule standard).

Express Funded 50K (après réussite)

  • Taille progressive : 2 contrats (20 micros) sous 1 500 $ de gain, 3 contrats à partir de 1 500 $, 5 contrats à partir de 2 000 $.
  • Perte maximale : 2 000 $ sous le plus haut solde de fin de journée, bloquée au point de départ une fois atteinte.
  • Retraits : 90 % pour vous, plafonnés à 2 000 $ par retrait depuis avril 2026, après des journées gagnantes.
  • Bots : autorisés sur le Combine et l'Express Funded, interdits sur le compte Live Funded.

Connexion automatique à Topstep

Ce qui est possible

  • Topstep ouvre une API (TopstepX, basée sur ProjectX) : un programme peut passer les ordres à votre place.
  • Autorisé sur le Combine et l'Express Funded, avec un abonnement API (29 $ par mois, 50 % de réduction avec le code « topstep »).
  • Le bot connaît déjà l'entrée, le TP, le SL et la taille en micros : il suffirait de les envoyer.

Ce qui bloque aujourd'hui

  • Les ordres doivent partir de votre propre appareil : serveur distant, VPS et VPN sont interdits. Le bot tourne sur les serveurs de GitHub : il ne peut pas trader lui-même.
  • Pas de compte de test pour l'API : les ordres touchent directement le compte.
  • Interdit sur le compte Live Funded, pas de trading à haute fréquence, surveillance obligatoire.
  • Le bot n'a pas encore prouvé qu'il gagne : ce compte simulé sert justement à le vérifier d'abord.
